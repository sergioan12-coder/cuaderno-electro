# Cuaderno de Electromagnetismo

Guía de estudio interactiva de electromagnetismo, construida a partir de los apuntes de clase.

**Abrir la app:** https://sergioan12-coder.github.io/cuaderno-electro/

## Secciones
- **Teoría:** fórmulas, producto cruz de vectores unitarios y tarjetas de repaso.
- **Visualizador 3D:** fuerza sobre una carga, sobre un cable, sobre una espira cerrada y campo de una carga en movimiento.
- **Ejercicios resueltos:** los ejemplos de clase, paso a paso.
- **Práctica:** problemas nuevos cada vez, con corrección automática.
- **Mi progreso:** aciertos y racha (se guardan en el navegador de cada estudiante).

Todo está en un solo archivo, `index.html`, sin dependencias de compilación.
